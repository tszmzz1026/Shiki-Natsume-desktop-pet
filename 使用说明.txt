四季夏目桌宠 单机可运行包 使用说明
=====================================

一、这个包是什么
----------------
这是一个已经把运行环境打包好的完整桌宠，包含：

1. Sakura 桌宠源码（app、main.py、install.bat、start.bat 等）
2. 四季夏目角色包 characters/Natsume（立绘 + 语音模型）
3. 内置 Python 运行环境 runtime
4. GPT-SoVITS 语音整合包 tts/g50（已精简日志和临时文件）
5. 长期记忆本地向量模型缓存 runtime/hf-cache
6. data/config 本地配置（包含 LLM API 配置，切勿随意外发）

另一台电脑不需要安装 Python，也不需要联网安装依赖。

二、运行要求
------------
- Windows 10/11 64 位。
- 项目必须放在纯英文路径下，例如：
  C:\sakura-natsume
  不要放在 C:\桌面\sakura-natsume 这类含中文的路径。
- 有 NVIDIA 显卡时 TTS 速度最快；无显卡也能用，但会慢一些。

三、怎么启动
------------
1. 把整个文件夹复制到目标电脑的英文路径。
2. 双击 start.bat。
3. 第一次打开会加载角色和语音配置，稍等片刻。

等价手动命令：

  runtime\python.exe main.py

如果启动异常，可先双击 install.bat 重新安装依赖，再运行 start.bat。

四、首次配置
------------
1. 打开设置窗口。
2. 模型页：填写 Base URL、API Key、模型名。
   - 必须使用支持多模态（图像识别）的模型。
   - 不要使用 DeepSeek 系列。
   - 点击"测试 API"确认连接成功。
3. 语音页：保持"启用 TTS 语音"开启。
   - 工作目录已配置为包内 tts/g50，一般不需要修改。
   - 首次调用 TTS 时服务会自动启动，模型加载可能需要几十秒。
4. 隐私页：按需要决定是否允许主动获取屏幕信息。

配置保存在 data/config/api.yaml，此文件不要上传到公开仓库。

五、包内附带的完整手册
----------------------
docs/使用说明.md 是完整使用手册，涵盖：

- 每个设置页说明
- 内置工具、截图、托盘、历史记录
- 长期记忆、TTS、MCP、插件
- 数据文件位置
- 常见问题与排查

六、常见问题
------------
1. 启动报"项目路径包含非英文字符"
   把整个目录移动到纯英文路径。

2. 没有声音
   确认 tts/g50 存在；确认语音页已启用 TTS；
   第一次语音生成要等模型加载完成。

3. API 测试失败
   检查 Base URL、API Key、模型名；屏幕观察需要多模态模型。

4. 记忆模型下载失败
   本包已内置缓存，不应再下载；若被删除，可设置
   HF_ENDPOINT=https://hf-mirror.com 后重启。

5. Playwright 网页工具不可用
   目标电脑联网后执行：
   runtime\python.exe -m playwright install chromium

七、体积说明
------------
本包较大，因为包含语音模型、Python 运行环境和 TTS 整合包。
请使用 U 盘、移动硬盘或局域网传输，不要通过网页聊天工具逐文件传输。
