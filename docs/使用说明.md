# Sakura Natsume 桌宠源码使用说明

## 1. 结论：源码能否独立使用

可以独立运行，但不是“解压即用”。

GitHub 仓库和桌面源码副本只包含程序代码。`.gitignore` 排除了以下目录，
因此换一台电脑或直接拉取仓库后，需要自己补齐运行环境：

| 项目 | 是否在仓库源码中 | 是否必需 |
|---|---|---|
| `runtime/`（内置 Python） | 否 | 可选，有系统 Python 3.10+ 可不用 |
| `characters/`（角色包） | 否 | 必需 |
| `tts/`（GPT-SoVITS 整合包） | 否 | 可选，只用字幕可不装 |
| `data/config/*.yaml`（本地配置） | 仅保留默认示例 | 运行时会自动生成/保存 |
| LLM API Key | 否 | 必需（聊天、记忆、屏幕观察） |

源码本身提供了 `install.bat`、`start.bat`、`scripts/install.sh`、
`scripts/start.sh`，补齐角色包和模型配置后即可运行。

## 2. 推荐的目录结构

```text
sakura-natsume/
├─ main.py                  # 程序入口
├─ install.bat / start.bat  # Windows 安装/启动
├─ app/                     # 核心代码
├─ characters/Natsume/      # 角色包（需自行补齐）
│  ├─ character.json
│  ├─ card.md
│  ├─ portraits/
│  └─ voice/
├─ data/config/             # api.yaml、system_config.yaml 等本地配置
├─ plugins/                 # 内置插件
├─ sdk/                     # 插件 SDK
├─ third_party/             # mem0 等内置依赖
├─ tests/                   # 单元测试
└─ docs/                    # 文档
```

角色包的最终结构必须是：

```text
characters/<角色id>/character.json
```

例如 `characters/Natsume/character.json`。除了 `character.json`，还需要
`card.md`、`portraits/`；语音可选，若有则需要 `voice/` 下的 GPT-SoVITS
模型和参考音频。

## 3. Windows 安装步骤

### 3.1 前置条件

- Windows 10/11 64 位。
- 项目路径必须全部是英文和数字字符。PySide6 在带中文的路径下可能崩溃，
  `install.bat`/`start.bat` 会主动检查。
  推荐路径：`C:\sakura-natsume` 或 `C:\Users\ASUS\Desktop\sakura-natsume`。
- 如果没有 `runtime/`，需要安装 Python 3.10 或更高版本，
  并保证 `python` 在 PATH 中。
- 能访问 pip 安装源；安装脚本已内置阿里云/清华镜像。

### 3.2 补齐角色包

任选一种方式：

1. 将现有完整项目中的 `characters/Natsume/` 整个目录复制到源码根目录。
2. 在软件首次启动的“角色”设置页导入 `.char` 文件。

### 3.3 安装依赖

双击 `install.bat`，脚本会：

1. 优先使用 `runtime/python.exe`，找不到则使用系统 `python`。
2. 使用国内镜像安装 `requirements.txt` 中的依赖。
3. 校验 PySide6 和 Playwright 是否可用。

等价的手动命令：

```powershell
cd C:\Users\ASUS\Desktop\sakura-natsume
runtime\python.exe -m pip install -r requirements.txt
```

如果使用系统 Python：

```powershell
python -m pip install -r requirements.txt
```

### 3.4 安装浏览器插件依赖（可选）

需要使用“打开网页/搜索/截图网页”等 Playwright 工具时，额外安装浏览器：

```powershell
runtime\python.exe -m playwright install chromium
```

或者：

```powershell
python -m playwright install chromium
```

不安装也不影响桌宠本体和普通聊天。

### 3.5 启动

双击 `start.bat`，或执行：

```powershell
cd C:\Users\ASUS\Desktop\sakura-natsume
runtime\python.exe main.py
```

系统 Python 版本：

```powershell
python main.py
```

首次启动如果没有找到 `characters/*/character.json`，程序会自动打开
“首次配置”设置窗口。

## 4. 首次运行配置

### 4.1 角色

在设置窗口选择“角色”：

- 点击“导入 .char”，选择包含立绘和语音的完整角色包。
- 或确认 `characters/Natsume/character.json` 已存在。
- 在下拉框中选择当前角色后保存。

### 4.2 模型（LLM API）

进入“模型”页，填写：

- Base URL：OpenAI 兼容接口地址，通常以 `/v1` 结尾。
- API Key：你的密钥，一般以 `sk-` 开头。
- 模型：服务商提供的模型名，可点击“检测模型”。

建议使用支持多模态（图像识别）的模型，否则屏幕观察功能会报错。
不要使用 DeepSeek 系列模型。

配置会保存到 `data/config/api.yaml`：

```yaml
llm:
  base_url: "https://api.openai.com/v1"
  api_key: "sk-你的密钥"
  model: "gpt-4.1-mini"
  timeout_seconds: 60
```

该文件已在 `.gitignore` 中，不会上传到 GitHub，请不要手工去掉忽略规则。

### 4.3 语音（TTS，可选）

进入“语音”页：

- 不配置 TTS 也可以正常使用，只是只有字幕没有声音。
- 勾选“启用 TTS 语音”。
- 可以使用软件内一键下载 GPT-SoVITS 整合包，也可以填入外置
  GPT-SoVITS 服务地址 `http://127.0.0.1:9880/tts`。

角色语音配置示例：

```yaml
tts:
  provider: gpt-sovits
  enabled: true
  gpt_sovits:
    api_url: "http://127.0.0.1:9880/tts"
    work_dir: "D:/sakura/tts/g50"
    ref_lang: ja
    text_lang: ja
    timeout_seconds: 60
```

注意：`work_dir` 是本机路径，不同电脑需要改成自己的 GPT-SoVITS 目录。

### 4.4 长期记忆（可选）

首次使用长期记忆时，程序会在后台下载
`sentence-transformers/all-MiniLM-L6-v2` 本地向量模型。

- 如果下载失败，可以设置 HuggingFace 镜像：
  ```powershell
  set HF_ENDPOINT=https://hf-mirror.com
  ```
- 或者在“记忆”设置页手动导入离线 ZIP 包。

### 4.5 MCP 与插件

- Web 搜索 MCP 默认开启，属于内置能力。
- Windows MCP 桌面控制是实验性功能，默认关闭；不确定时保持关闭。
- `playwright_browser` 插件默认开启，但需要先安装 Chromium
  （见 3.4 节）。

## 5. macOS / Linux 源码运行

macOS 和 Linux 请使用：

```bash
cd sakura-natsume
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

macOS 还需要注意：

- python.org 安装的 Python 可能需要先运行
  `/Applications/Python 3.x/Install Certificates.command`。
- Apple Silicon 的 Rosetta/x86 环境需要额外执行
  `pip install -r requirements-macos-intel.txt`。
- 详细说明见 `docs/MACOS_SETUP.md`。

## 6. 运行测试（可选）

```powershell
cd C:\Users\ASUS\Desktop\sakura-natsume
runtime\python.exe -m pytest tests/unit
```

或：

```powershell
python -m pytest
```

## 7. 常见问题

### 启动时报“项目路径包含非英文字符”

把项目移动到纯英文路径，例如 `D:\sakura-natsume`。

### 提示找不到角色包

确认根目录存在 `characters/Natsume/character.json`，或在首次设置窗口中
导入 `.char` 文件。

### API 测试失败 / 401

- 检查 Base URL 是否以 `/v1` 结尾。
- 检查 API Key 前后是否有空格。
- 检查模型名是否正确、是否支持多模态。
- 检查本机到模型服务商的网络是否可达。

### 只有字幕没有声音

- 确认角色包包含 `voice/` 目录。
- 确认 TTS 设置已启用。
- 确认 GPT-SoVITS 服务已启动，`api_url` 可访问。
- 程序启动日志若提示“配置无效，已禁用 TTS”，按日志修正配置。

### Playwright 工具报找不到浏览器

执行：

```powershell
runtime\python.exe -m playwright install chromium
```

### 记忆模型下载失败

设置 `HF_ENDPOINT=https://hf-mirror.com` 后重启，或在“记忆”设置页
手动导入 `models--sentence-transformers--all-MiniLM-L6-v2` 离线包。

## 8. 数据与安全

- `data/config/api.yaml` 包含 API Key，已加入 `.gitignore`，不要提交。
- `data/chat_history/`、`data/memory`、`data/tts_bundles/` 等运行时数据
  已加入 `.gitignore`。
- `runtime/`、`characters/`、`tts/` 属于大型本地资源，不在 GitHub 源码中。
- 发布或分发源码前，请确认没有把本地密钥、聊天记录或角色语音模型
  复制到公开仓库。
